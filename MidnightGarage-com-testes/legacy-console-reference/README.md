# Código original de console (referência)

Estes arquivos são cópias do projeto original em Java console, guardadas para referência.
Eles **não fazem parte da compilação Maven** da nova API. A aplicação executável é a que está em
`src/main/java/br/org/edu/ifrn/MidnightGarage`.

Os arquivos originais `usuarios.txt` e `logs.txt` também ficam aqui como cópia de segurança.
A nova aplicação usa os arquivos em `data/`.
